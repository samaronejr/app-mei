{% extends "portal/base.html" %} {% load i18n ptbr %}{% comment %} The company's own name fills the layout's heading rather than being written as a second heading underneath it. One heading per page is the shell's contract, and a page whose subject is a single company has nothing to call itself that is truer than its name. The value elements carry no attributes and must keep none: the isolation suite asserts the obligation count by its exact rendered element, and that assertion is the only falsifiable half of the test proving the database confined the count rather than the view filtering it. Figures line up column-wise because the list sets fixed-width numerals, which is an inherited property and therefore reaches them from the parent. The obligation type is named HERE rather than by the view, and that is a rule rather than a preference. A test greps every source file under apps/ for the quoted obligation code, so that the deadline engine stays driven by its seeded rule rows instead of a ladder of branches on the code -- and it cannot tell a display label apart from the branch it exists to prevent. The view hands down the raw code and this page decides what to call it, with the code itself as the fallback, so a type nobody has labelled yet renders as the string a Receita document already uses rather than as nothing. Every address is written with the direct form of the url tag. Captured into a variable it fails SILENTLY on a name the portal tree does not carry, emitting an empty href on a page that still answers 200; written straight into the anchor it raises during rendering, which is a failure somebody sees. Standing is never carried by colour alone. Each badge holds the word as well, because a green pill means nothing to a reader who cannot see it and little to one who has not learned this product's palette. The reassurance is deliberately bounded. "Em dia com as obrigações que acompanhamos" is a claim about this firm's book and nothing wider, and the qualifier is the honest part rather than the hedge: a MEI owner may hold a debt her accountant has never been told about, and a portal that answered "você está em dia" flat would be telling her something this product cannot know. The late branch is bounded the other way -- it names the count AND says the figure grows while it goes unpaid, because a number with no consequence reads as a filing detail rather than a bill. The CNPJ is punctuated by the `cnpj_mask` filter and never by a model property, so that one filter is the single place this product decides what a CNPJ looks like. The column is local to `clients_clientcompany`, which the portal role holds SELECT on and the middleware has already read, so the filter costs nothing the property did not. DAS-MEI rolls FORWARD off a non-business day; DASN-SIMEI does NOT roll at all and stays on 31 May even when that is a Saturday (Resolução CGSN nº 140/2018 art. 109, recorded in docs/regulatory-watch.md).
