{% load i18n %}{% comment %} The upload control of one request (T11). A plain multipart POST that works without scripts; with them, htmx posts it and the `uploadList` component (static/js/app.js) shows progress, lets the client cancel, and keeps the chosen file for a retry. The component reads its limits from data attributes rather than expressions: `x-*` values are evaluated after the browser decodes entities, so nothing is interpolated into them (tests/ui/test_csp.py). The accepted types are a recommendation; the server enforces the size cap and remains the authority. String literals inside a tag that sits within an HTML attribute are single-quoted, because the class-token scanner reads attributes with a regex. {% endcomment %}
