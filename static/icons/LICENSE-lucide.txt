Lucide icon glyphs, vendored as inline-SVG template partials.

    Source    https://github.com/lucide-icons/lucide
    Version   1.28.0            (git tag 1.28.0, published 2026-07-30)
    Files     icons/<name>.svg at that tag, hand-copied into
              templates/partials/pure/icons/<name>.html

No package is installed and nothing is fetched at build time. The path data in each
partial is byte-identical to the pinned release; only the root element differs, which
drops width/height (the `.icon` class owns the box) and adds class, aria-hidden and
focusable.

Four of this project's glyph names are names Lucide retired before its 1.0 release --
upstream marked them `"toBeRemovedInVersion": "v1.0"` and they no longer resolve at
1.28.0. The file here and the file upstream are the same glyph under two names:

    templates/partials/pure/icons/     lucide 1.28.0 icons/
    alert-triangle.html               triangle-alert.svg
    check-circle.html                  circle-check.svg
    home.html                          house.svg
    x-circle.html                      circle-x.svg

The other twelve match upstream verbatim.

6 of the 16 glyphs shipped here -- alert-triangle, chevron-right, download, info, upload, x-circle -- appear in the
Feather-derived list below, so the MIT notice covers them in addition to the ISC
licence. That is why the whole upstream LICENSE is reproduced rather than its ISC
section alone: MIT requires its notice travel with every copy, and this project
copies those glyphs into its own templates.
