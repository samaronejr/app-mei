{% load i18n %}{% comment %} A data table: caption, sortable headers, dense or comfortable rows. Context: caption -- required. What the table lists; a screen reader announces it on entry. `caption_hidden` keeps it in the accessibility tree only, for a table already titled by the heading above it. columns -- a list of {label, numeric, sort, sort_url}. `sort` is the current `aria-sort` value (ascending | descending) or empty; `sort_url` makes the header a link that re-sorts server-side. rows -- the rows to render. row_template -- the template that renders ONE `` for `row`. Cells stay the caller's, because a cell may hold a link, a badge or a figure, and only the screen knows which. comfortable -- truthy for the roomier row height; dense is the default. empty_title -- the empty state's title when `rows` is empty. empty_message -- its next step. Sorting, filtering and paging are server-side (S5.6): a header link is a GET, so the order lives in the URL and Back restores it. The header row is sticky inside the scroll container, which is the table's own `.table-wrap` -- never the page. The container is a focusable region named by the caption: on a phone a wide table scrolls inside it, and a scroller with no focusable content is otherwise out of reach of a keyboard (axe: scrollable-region-focusable). {% endcomment %}
