{% load i18n %}{% comment %} One form field -- label, control, help, error -- from plain data. `partials/pure/field.html` renders a Django BoundField and stays the partial for every Form. This one exists for the controls that have no Form behind them: a filter bar's query parameters, a search box, a select the view resolves itself. The accessibility contract is the same one, written the same way: * the label is always rendered, always visible, and bound by `for`; * `aria-describedby` names the help id, the error id, both, or is omitted -- never emitted empty; * `aria-invalid="true"` appears only while there are errors. Context: name -- the submitted parameter name. field_id -- the control's id. Required: the label, help and error ids all derive from it. label -- visible pt-BR label. type -- text (default) | search | email | number | date | select | textarea. value -- current value; for a select, the value of the selected option. options -- for a select: a list of {value, label}. required -- truthy marks the control required. help_text -- optional guidance under the control. errors -- optional list of pt-BR messages; any entry marks the field invalid. {% endcomment %}
