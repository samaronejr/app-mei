{% load i18n %}{% comment %} A multi-file picker that shows what is about to be sent, and what already arrived. Context: input_name -- the submitted field name. input_id -- the input's id; help and status ids derive from it. label -- visible pt-BR label. accept -- the browser `accept` list (".pdf,.xml,image/*"); empty accepts all. max_bytes -- per-file ceiling in bytes; empty means no client-side ceiling. max_label -- that ceiling in words ("10 MB"), used in the refusal message. help_text -- guidance under the picker: what to send, and the limits. received -- optional list of {name, size_label, state, state_label} for files the server already holds, each drawn with `status_badge.html`. The `uploadList` component reads the limits from data attributes rather than an expression: `x-*` values are evaluated after the browser decodes entities, so the project interpolates nothing into them (tests/ui/test_csp.py). It lists every chosen file with its size, refuses the ones over the ceiling or of a type not accepted -- dropping them from the input so they are never sent -- and lets the reader remove any file before submitting. The status line is a polite live region, so each change is announced once. The browser check is a courtesy. The server re-checks size and type and remains the authority; a file this list accepted can still be refused there. Without script the input is an ordinary multi-file input and the form still submits; only the preview list is missing. {% endcomment %}
