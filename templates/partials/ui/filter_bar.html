{% load i18n %}{% comment %} A filter bar: a plain GET form whose state lives in the URL. Context: label -- accessible name of the search landmark ("Filtrar clientes"). action -- where the form submits; empty submits to the current address. filters -- a list of field dicts, each rendered by `partials/ui/field.html` (name, field_id, label, type, value, options, help_text). clear_url -- optional; where "Limpar filtros" leads, normally the bare list. submit_label -- optional; defaults to "Filtrar". Filters are query parameters, so Back restores them and a filtered view can be bookmarked or sent to a colleague (S5.6). The form carries no hx-* attribute: HTMX reads such an attribute after the browser has decoded it, which is why the project interpolates nothing into one. A caller wanting a swap wraps this include in its own boosted element carrying `hx-sync`, the way `partials/pure/pagination.html` describes -- and without script the button still submits an ordinary GET. {% endcomment %}
