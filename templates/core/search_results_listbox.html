{% load i18n %}{% comment %} The palette's results, swapped into #palette-results by HTMX (`hx-get` on the palette field). A listbox of options the combobox points at with aria-activedescendant: focus never leaves the field, so the options are not focusable and are not links -- an interactive element inside an option is one a screen reader cannot reach. The destination rides in data-href, which the `palette` component (static/js/app.js) follows on Enter or click; it is a path from `reverse()`, never tenant text. Option ids are positional, not row ids: an id is an attribute every assistive technology reads, and a row's primary key has no business being announced. Context: the same as core/search.html.
