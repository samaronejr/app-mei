The indicator is named by selector and lives in the form, not in the strip: #calendario-strip is replaced outerHTML, so an element inside it is destroyed by the very swap it exists to report on. The select is written out rather than passed through partials/pure/field.html: that partial reads a Django BoundField, and this filter is a bare query parameter the view resolves itself. It carries the three classes the partial emits, so the two render identically, and it owes neither aria-invalid nor an aria-describedby chain because it has no error and no help line.
