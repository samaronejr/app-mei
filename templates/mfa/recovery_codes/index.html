THE THREE SCRIPTS UPSTREAM LOADS ARE NOT CARRIED OVER. Upstream's version of this screen redeclares `extra_body` to pull in two static bundles plus an inline scripting element that drives a "I have saved my codes" checkbox. The CSP in `apps/security/csp.py` is `script-src 'self'` with no inline allowance, so that element would never execute — it would fail silently in the console and leave the checkbox inert. `MFA_RECOVERY_CODES_SHOW_ONCE` is False here besides, which is the setting that makes that checkbox appear at all, so the whole apparatus is unreachable twice over. This file therefore declares no `extra_body` and the codes are simply shown. The tag itself is not spelled anywhere in this comment. `tests/ui/templates_scan.py` reads template source with regexes that do not know a comment from markup, and prose that spells a tag or an attribute value registers as the real thing — the same reason `partials/pure/notice.html` describes its class attribute rather than writing it. WHAT THE COPY HAS TO SAY, AND WHY. These codes are the last way in when the phone is gone — the account has no other factor, `MFA_SUPPORTED_TYPES` lists totp and recovery codes only. Two facts decide whether they work when that day comes, and neither is deducible from a list of strings: * each code works ONCE and is then spent, so a reader who has used three still has a finite number left, which is what the count above the list is for; * storing them in the password manager that already holds the password defeats them entirely. One compromised vault then yields both factors, and the whole reason for the second factor was that the first one might leak. The list is a readonly textarea rather than prose so it can be selected and copied in one gesture, and it carries no name — it is not posted anywhere. Reachable on both hosts, so no ORM, no capability, and every url name below is mounted by `config.urls` and `apps/portal/urls.py` alike. The three `can_*` flags come from the view's context, not from this project's authorization matrix. {% endcomment %} {% block head_title %}{% translate "Códigos de recuperação" %}{% endblock head_title %} {% block content %} {% element h1 %} {% translate "Códigos de recuperação" %} {% endelement %}
