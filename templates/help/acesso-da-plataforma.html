{% blocktranslate trimmed %}A regra{% endblocktranslate %}

{% blocktranslate trimmed %}A equipe da plataforma só entra nos dados do seu escritório com um pedido aprovado pelo responsável pela conta. Isso vale também para os administradores da plataforma. Sem aprovação, ou depois que o acesso termina, a entrada é negada.{% endblocktranslate %}

{% blocktranslate trimmed %}O pedido{% endblocktranslate %}

{% blocktranslate trimmed %}Quem precisa de acesso abre um pedido e escreve a finalidade. O pedido aparece em Configurações, na página Acesso de suporte, com o e-mail de quem pediu, a finalidade e a data. Enquanto você não decide, o pedido não libera nada. Para negar, use Recusar.{% endblocktranslate %}

{% blocktranslate trimmed %}O que você escolhe ao autorizar{% endblocktranslate %}

  • {% blocktranslate trimmed %}Tipo de acesso: Somente leitura, ou Leitura e configurações da firma. O segundo também permite alterar as configurações do escritório.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Clientes visíveis: marque na lista os clientes que o suporte pode ver. Se nenhum for marcado, o suporte vê só dados gerais do escritório e nenhum dado de cliente.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Duração: de 1 a 72 horas. A página sugere 4 horas.{% endblocktranslate %}

{% blocktranslate trimmed %}Durante o acesso{% endblocktranslate %}

  • {% blocktranslate trimmed %}Em todas as páginas do escritório, quem está no suporte vê o aviso Acesso de suporte ativo, com o tipo de acesso e o horário em que ele encerra automaticamente.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Documentos não podem ser abertos nem baixados pelo suporte.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Nas mensagens, o assunto e as anotações da equipe aparecem como •••. Nos cartões de aprovação, o texto, o remetente e os destinatários ficam ocultos.{% endblocktranslate %}
  • {% blocktranslate trimmed %}O suporte não aprova, não decide envios, não revisa documentos e não baixa arquivos. Essas ações são recusadas pelo sistema, não apenas escondidas da tela.{% endblocktranslate %}

{% blocktranslate trimmed %}O que fica registrado{% endblocktranslate %}

  • {% blocktranslate trimmed %}Cada página que o suporte abre durante o acesso, inclusive as recusadas, fica registrada no histórico de auditoria do escritório, com o endereço, a data e o resultado.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Na página Acesso de suporte, o Histórico de acessos mostra cada autorização: quem pediu, a finalidade, quando foi aprovada, até quando vale, o tipo de acesso e quando foi encerrada.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Em cada autorização do Histórico de acessos, o link Ver trilha de auditoria abre a trilha daquele acesso. Ela lista as páginas que o suporte abriu, com o método e o endereço, sem os dados enviados, e as etapas do acesso: o pedido, a autorização e o encerramento. Cada linha mostra quando aconteceu e qual conta agiu.{% endblocktranslate %}
  • {% blocktranslate trimmed %}A trilha mostra os 100 registros mais recentes, do mais novo para o mais antigo, e indica quando o acesso já expirou. Só o responsável pela conta abre essa página; quem está no suporte não consegue abri-la.{% endblocktranslate %}

{% blocktranslate trimmed %}Encerrar{% endblocktranslate %}

{% blocktranslate trimmed %}O responsável pela conta pode encerrar o acesso a qualquer momento, no Histórico de acessos, com o botão Encerrar acesso. A partir da próxima página que o suporte abrir, a entrada é negada. No fim do prazo, o acesso também termina sozinho, já na página seguinte.{% endblocktranslate %}

{% blocktranslate trimmed %}Um acesso nunca é prorrogado. Para continuar, o suporte precisa abrir um novo pedido, e o responsável pela conta precisa aprová-lo de novo.{% endblocktranslate %}
