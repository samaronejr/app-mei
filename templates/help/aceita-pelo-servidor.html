{% blocktranslate trimmed %}O que significa{% endblocktranslate %}

{% blocktranslate trimmed %}"Aceita pelo servidor de e-mail" quer dizer que o nosso provedor de envio respondeu que recebeu a mensagem para enviar. Guardamos essa resposta e o horário.{% endblocktranslate %}

{% blocktranslate trimmed %}O que não significa{% endblocktranslate %}

  • {% blocktranslate trimmed %}Não confirma que a mensagem chegou à caixa de entrada. Ela pode ir para o spam ou ser recusada depois pelo servidor de quem recebe.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Não confirma que alguém leu. O produto não rastreia abertura de e-mail.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Por isso a tela nunca diz que a mensagem chegou ao destino só porque o servidor aceitou.{% endblocktranslate %}

{% blocktranslate trimmed %}Resultado incerto{% endblocktranslate %}

{% blocktranslate trimmed %}Às vezes a conexão cai no meio do envio. Nesse caso a tela mostra Resultado incerto: o envio pode ter ocorrido. O sistema confirma antes de tentar de novo, para o cliente não receber a mesma mensagem duas vezes.{% endblocktranslate %}

{% blocktranslate trimmed %}O que conta como confirmação{% endblocktranslate %}

{% blocktranslate trimmed %}Quando o cliente, logado no portal, abre ou baixa uma publicação, isso é registrado pelo próprio sistema. Quando ele marca que está ciente de algo no portal, isso também fica registrado.{% endblocktranslate %}
