{% blocktranslate trimmed %}Seu acesso{% endblocktranslate %}

{% blocktranslate trimmed %}A sua contabilidade envia um convite por e-mail. Siga o link do convite para criar o seu acesso. Use sempre o mesmo e-mail que a contabilidade cadastrou.{% endblocktranslate %}

{% blocktranslate trimmed %}Responder aos pedidos{% endblocktranslate %}

  • {% blocktranslate trimmed %}Na página inicial do portal aparece o que a contabilidade está pedindo, com o documento, a empresa e o prazo.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Abra o pedido, escolha o arquivo e envie. A página confirma que o arquivo foi recebido.{% endblocktranslate %}
  • {% blocktranslate trimmed %}A contabilidade revisa o arquivo. Se faltar algo, aparece Precisamos da sua ajuda, dizendo o que corrigir.{% endblocktranslate %}

{% blocktranslate trimmed %}Mais de uma empresa{% endblocktranslate %}

{% blocktranslate trimmed %}Se você responde por mais de uma empresa, escolha a empresa antes de enviar. Cada pedido mostra a qual empresa ele se refere.{% endblocktranslate %}

{% blocktranslate trimmed %}Publicações e pagamentos{% endblocktranslate %}

{% blocktranslate trimmed %}Publicações são documentos que a contabilidade deixa para você, como guias. Quando você abre ou baixa uma publicação, a contabilidade fica sabendo.{% endblocktranslate %}

{% blocktranslate trimmed %}Um pagamento que você informa aparece como informado até a contabilidade conferir. Isso não é uma confirmação da Receita.{% endblocktranslate %}

{% blocktranslate trimmed %}Quando o acesso termina{% endblocktranslate %}

{% blocktranslate trimmed %}Se a contabilidade encerra o serviço da sua empresa, o acesso ao portal termina depois de um prazo. A partir daí, o portal mostra a página Acesso não permitido. Se você acha que o acesso deveria continuar, fale com a sua contabilidade.{% endblocktranslate %}

{% blocktranslate trimmed %}Dúvidas{% endblocktranslate %}

{% blocktranslate trimmed %}Dúvidas sobre um pedido ou um prazo devem ir direto para a sua contabilidade. Para exercer os seus direitos sobre dados pessoais, use o canal LGPD indicado no rodapé.{% endblocktranslate %}
