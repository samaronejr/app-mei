{% blocktranslate trimmed %}A regra{% endblocktranslate %}

{% blocktranslate trimmed %}Envios que produzem efeito no cliente — a comunicação que pede, entrega ou decide algo — só saem depois que alguém com permissão aprova exatamente o que vai sair: o texto, os destinatários e os documentos anexados. O cartão de aprovação mostra tudo isso antes dos botões de decisão, com cada destinatário pelo nome do contato.{% endblocktranslate %}

{% blocktranslate trimmed %}Avisos e lembretes sem cartão{% endblocktranslate %}

{% blocktranslate trimmed %}Avisos, lembretes e convites que seguem o modelo do playbook enviado sem cartão de aprovação: a equipe autorizou esse fluxo na configuração do ciclo, e cada envio fica registrado do mesmo jeito.{% endblocktranslate %}

{% blocktranslate trimmed %}Quando algo muda depois da aprovação{% endblocktranslate %}

{% blocktranslate trimmed %}Se o conteúdo, um destinatário ou um anexo mudar depois de aprovado, a aprovação deixa de valer e o cartão avisa que está desatualizado. É preciso revisar e aprovar de novo.{% endblocktranslate %}

{% blocktranslate trimmed %}Revogar{% endblocktranslate %}

{% blocktranslate trimmed %}Uma aprovação pode ser revogada enquanto o envio não começou. Se o envio já tiver começado, a tela mostra o estado real dele, sem fingir que foi cancelado.{% endblocktranslate %}

{% blocktranslate trimmed %}Quem aprova{% endblocktranslate %}

{% blocktranslate trimmed %}Em Gestão, na página de aprovações, o escritório define a política de aprovação. Operações em lote mostram uma prévia com cada item antes de executar.{% endblocktranslate %}
