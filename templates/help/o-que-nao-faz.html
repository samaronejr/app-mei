{% blocktranslate trimmed %}Não transmite declarações{% endblocktranslate %}

{% blocktranslate trimmed %}O {{ product_name }} consulta a Receita e obtém documentos oficiais, como o relatório de situação fiscal e a guia DAS. Ele não transmite declarações, como a declaração anual do MEI, não muda opções de regime e não pede parcelamento. Isso continua sendo feito pela equipe nos sistemas oficiais.{% endblocktranslate %}

{% blocktranslate trimmed %}Não faz pagamentos{% endblocktranslate %}

{% blocktranslate trimmed %}O {{ product_name }} não paga guias nem débitos e não guarda dados bancários. A guia DAS que ele emite é um documento para o cliente pagar. Um pagamento só aparece como "Pagamento encontrado na Receita" quando a consulta de pagamentos o encontra.{% endblocktranslate %}

{% blocktranslate trimmed %}Não calcula ISS{% endblocktranslate %}

{% blocktranslate trimmed %}O {{ product_name }} não apura nem calcula ISS e não emite guias municipais.{% endblocktranslate %}

{% blocktranslate trimmed %}Uma consulta mostra o que a fonte informou no momento da consulta. Nenhum resultado é uma certidão, e as decisões fiscais continuam com o contador responsável.{% endblocktranslate %}
