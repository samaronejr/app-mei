{% blocktranslate trimmed %}Exportar os dados{% endblocktranslate %}

{% blocktranslate trimmed %}Em Configurações, na área Plano, uso e encerramento, o responsável pela conta pode pedir uma exportação. Ela gera um arquivo ZIP com planilhas CSV de clientes, serviços contratados, ciclos, solicitações e dados das mensagens, mais uma lista dos documentos.{% endblocktranslate %}

{% blocktranslate trimmed %}A exportação é preparada em segundo plano. Quando estiver pronta, o download aparece na mesma página.{% endblocktranslate %}

{% blocktranslate trimmed %}Encerrar a conta{% endblocktranslate %}

  • {% blocktranslate trimmed %}O responsável pela conta agenda uma data de encerramento. Até lá, tudo funciona normalmente.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Depois da data, a conta fica somente para leitura, e a exportação continua disponível por 90 dias.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Depois desse prazo, os dados são removidos conforme a regra de retenção de cada tipo de dado. Hoje essa remoção ainda não é executada: ela aguarda a revisão jurídica dos prazos.{% endblocktranslate %}

{% blocktranslate trimmed %}Cobrança{% endblocktranslate %}

{% blocktranslate trimmed %}Uma cobrança em atraso nunca bloqueia a exportação. Uma conta suspensa fica somente para leitura, e a exportação continua permitida.{% endblocktranslate %}

{% blocktranslate trimmed %}Enquanto a operação da plataforma não registra a cobrança manual da sua conta, a página Plano, uso e encerramento mostra Registro pendente, e a próxima cobrança aparece como um traço. A página abre normalmente nesse estado.{% endblocktranslate %}

{% blocktranslate trimmed %}Quando um cliente sai do escritório{% endblocktranslate %}

{% blocktranslate trimmed %}Ao terminar o serviço de um cliente, o acesso dele ao portal termina depois de um prazo de carência, de 30 dias por padrão. Os registros continuam guardados conforme a regra de retenção.{% endblocktranslate %}

{% blocktranslate trimmed %}Depois desse prazo, o portal mostra ao cliente a página Acesso não permitido, em português, com a orientação de falar com o escritório de contabilidade.{% endblocktranslate %}

{% blocktranslate trimmed %}Retenção{% endblocktranslate %}

{% blocktranslate trimmed %}As regras de retenção e as retenções legais em vigor aparecem em Configurações, na página de retenção.{% endblocktranslate %}
