{% blocktranslate trimmed %}O que a cobertura mostra{% endblocktranslate %}

{% blocktranslate trimmed %}A cobertura mostra o que sabemos sobre cada obrigação e de onde veio essa informação. Ela não mostra a situação oficial da obrigação no órgão.{% endblocktranslate %}

{% blocktranslate trimmed %}Quatro estados diferentes{% endblocktranslate %}

  • {% blocktranslate trimmed %}Sem informação: nenhuma fonte cobre este item. Nunca aparece como se estivesse tudo bem.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Desatualizado: a última verificação é antiga, e a tela diz há quanto tempo.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Pagamento informado (não confirmado na Receita): o comprovante foi registrado pela equipe ou enviado pelo cliente. Enquanto não for conferido, continua marcado como aguardando conferência.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Verificado: só aparece quando uma fonte verificada sustenta a informação.{% endblocktranslate %}

{% blocktranslate trimmed %}Como está hoje{% endblocktranslate %}

{% blocktranslate trimmed %}Hoje o produto não consulta a Receita nem outros órgãos. Por isso nenhuma obrigação aparece como confirmada pela autoridade. Cada estado usa cor, ícone e texto juntos, nunca só a cor.{% endblocktranslate %}
