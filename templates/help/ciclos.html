{% blocktranslate trimmed %}O que é um ciclo{% endblocktranslate %}

{% blocktranslate trimmed %}Um ciclo é o trabalho de um cliente em uma competência, por exemplo o ciclo de março/2026. Ele nasce de uma versão publicada de um playbook e reúne as solicitações ao cliente, os documentos recebidos e revisados, as pendências e tudo o que for enviado ao cliente.{% endblocktranslate %}

{% blocktranslate trimmed %}Documentos e pendências{% endblocktranslate %}

  • {% blocktranslate trimmed %}Cada arquivo enviado pelo portal fica registrado com quem enviou, quando e uma impressão digital do conteúdo.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Quem revisa aceita o documento ou pede correção. A revisão fica registrada com a pessoa, a data e a versão revisada.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Em PDFs e XMLs legíveis, um documento de outra empresa, ou com CNPJ diferente, vira uma pendência com responsável e prazo. Fotos, imagens e escaneados ficam como não verificável: a plataforma não lê texto em imagem, então a conferência é manual, do escritório.{% endblocktranslate %}

{% blocktranslate trimmed %}Quando o ciclo termina{% endblocktranslate %}

{% blocktranslate trimmed %}O ciclo fica Concluído quando cada item obrigatório foi aceito ou dispensado com motivo, cada pendência foi resolvida, e cada envio ao cliente foi aprovado e executado ou cancelado de forma explícita.{% endblocktranslate %}

{% blocktranslate trimmed %}Se isso não acontecer, ele pode ser fechado como Encerrado com pendências. Os motivos ficam escritos no ciclo.{% endblocktranslate %}

{% blocktranslate trimmed %}Um ciclo fechado pode ser reaberto por quem tem permissão, e a reabertura fica registrada.{% endblocktranslate %}

{% blocktranslate trimmed %}Índice de evidências{% endblocktranslate %}

{% blocktranslate trimmed %}Ao fechar, o ciclo gera um índice do que foi pedido, recebido, revisado e enviado. É o registro do próprio sistema. Não é um documento com validade jurídica certificada.{% endblocktranslate %}
