{% blocktranslate trimmed %}A regra{% endblocktranslate %}

{% blocktranslate trimmed %}Ninguém do suporte entra na conta do seu escritório sem um pedido aprovado pelo responsável pela conta. Não existe acesso invisível.{% endblocktranslate %}

{% blocktranslate trimmed %}O que o pedido diz{% endblocktranslate %}

  • {% blocktranslate trimmed %}A finalidade do acesso.{% endblocktranslate %}
  • {% blocktranslate trimmed %}O escopo: somente leitura, ou leitura e ajuste de configurações.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Quais clientes. Sem clientes indicados, o suporte vê apenas dados gerais do escritório.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Até quando vale. O prazo máximo é de 72 horas.{% endblocktranslate %}

{% blocktranslate trimmed %}Durante o acesso{% endblocktranslate %}

  • {% blocktranslate trimmed %}Todas as páginas mostram o aviso de acesso de suporte ativo, com o horário de término.{% endblocktranslate %}
  • {% blocktranslate trimmed %}O conteúdo dos documentos e o texto das mensagens ficam ocultos para o suporte.{% endblocktranslate %}
  • {% blocktranslate trimmed %}O suporte não aprova ações, não envia mensagens e não baixa documentos.{% endblocktranslate %}
  • {% blocktranslate trimmed %}Cada acesso fica registrado, e o responsável pela conta vê esse registro.{% endblocktranslate %}

{% blocktranslate trimmed %}Revogar{% endblocktranslate %}

{% blocktranslate trimmed %}O responsável pela conta pode revogar o acesso a qualquer momento, e a revogação vale na hora. Um acesso nunca é prorrogado sem um novo pedido aprovado.{% endblocktranslate %}
