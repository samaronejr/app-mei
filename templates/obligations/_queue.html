{% load i18n %} {% comment %} The fragment an HTMX request receives, and the same markup the full page embeds. One template for both, so a partial refresh can never drift from a fresh load. Pagination is ordinary anchors inside an hx-boost container: the page number belongs in href, which the browser treats as a URL, and never in an hx-* attribute, which HTMX would treat as one more place a decoded value lands. Those anchors moved to a pure partial the client portal shares; the boosted container stayed behind. The wrapper is the caller's precisely so the partial stays free of any request vocabulary and costs no query, which is what lets a product shipping no JavaScript reuse it unchanged. The empty cell spans spec.headings, the same source the header row is built from. Four queues render through this one template and their header counts differ, so a literal here is wrong for at least three of them -- and a table whose empty row is wider than its own header is what a screen reader reports as a malformed grid. #fila is the swap target, so it carries the name static/js/app.js announces after a swap. Without one the announcement degrades to a generic sentence, and an accountant who filtered four queues in a row hears the same words every time. {% endcomment %}
